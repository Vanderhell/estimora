# Changelog

## 0.2.0

- Namespaced the public API with the `estimora_` prefix and moved public headers under `include/estimora/`.
- Added a namespaced CMake target, install/export package, independent header checks, and a quick-start example.
- This is a source-level breaking change from 0.1.0; see the API reference for the new headers and symbols.
- No production algorithm changes are included.
